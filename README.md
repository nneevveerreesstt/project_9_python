# Проверка гипотез в Python и анализ A/B-теста
## Бизнес-контекст
Проект состоит из двух независимых аналитических задач:
- Яндекс Книги - проверка продуктовой гипотезы о различиях в поведении пользователей из Москвы и Санкт-Петербурга.
- BitMotion Kit - оценка результатов A/B-теста новой версии интерфейса интернет-магазина.


## Цель проекта
Отработать полный цикл проверки статистических гипотез: от постановки задачи и предобработки данных до интерпретации результатов и формулирования бизнес-выводов.

## Задачи

### Часть 1. Проверка гипотезы о различиях между городами (Яндекс Книги)

- Загрузить и предобработать данные пользователей из Москвы и Санкт-Петербурга.
- Проверить наличие дубликатов в `user_id`, сравнить размеры групп и описательные статистики.
- Сформулировать и проверить статистическую гипотезу:
  - **H₀**: μ(СПб) ≤ μ(Москва)
  - **H₁**: μ(СПб) > μ(Москва)
- Применить **односторонний двухвыборочный t-тест** (при необходимости — тест Уэлча).
- Подготовить аналитическую записку с:
  - обоснованием выбора теста и уровня значимости (α);
  - значением p-value;
  - интерпретацией результата;
  - гипотезами о причинах наблюдаемого эффекта.

### Часть 2. Анализ A/B-теста интернет-магазина BitMotion Kit

- Загрузить данные участников теста и события пользователей за 2020 год.
- **Проверить корректность проведения теста**:
  - равномерность распределения по группам A и B;
  - пересечения пользователей между тестами;
  - соответствие периода теста ТЗ;
  - влияние устройств регистрации на распределение.
- **Проанализировать результаты**:
  - рассчитать конверсию в покупку в течение 7 дней после регистрации;
  - сравнить конверсии групп A и B;
  - проверить достижение целевого прироста **+3 п.п.**;
  - оценить статистическую значимость различий.
   
Основной инструмент - `Python`.
